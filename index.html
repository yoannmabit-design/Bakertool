📥📤 Import / Export Excel — Fiches Techniques

Format : une ligne par ingrédient. Colonnes : Fiche, Catégorie, Vendable (Oui/Non), Pièces, Type (Brut/Composite), Ingrédient, Quantité (g), Farine (Oui/Non). L'import fusionne par nom de fiche (une fiche déjà existante est remplacée avec le contenu du fichier, les autres restent intactes). Si un ingrédient "Brut" n'existe pas dans la base Ingrédients, il est ajouté automatiquement (prix à 0, à compléter). Rien n'est enregistré sur Firebase tant que tu ne cliques pas sur les boutons "Enregistrer" ci-dessus et dans l'onglet Ingrédients.
